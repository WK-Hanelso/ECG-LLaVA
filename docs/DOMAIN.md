# ECG 도메인 명세

이 문서는 파일 포맷이 아니라 **신호 자체가 무엇인지** 다룬다.
데이터 명세는 [DESIGN.md](../DESIGN.md) 2절에, 여기서는 그 숫자가 생리적으로 무엇을 뜻하는지 적는다.

본문의 수치는 대부분 이 저장소의 PTB-XL v1.0.3 캐시에서 직접 계산한 값이다.
교과서 값을 인용한 부분은 그렇다고 명시했다.

---

## 1. 심전도는 물리적으로 무엇인가

심장 근육 세포는 수축하기 직전에 세포막 안팎의 이온 농도가 뒤집힌다.
안쪽이 음전위였다가 양전위가 되는 현상을 **탈분극(depolarization)** 이라 하고,
수축이 끝나고 원래 전위로 돌아가는 것을 **재분극(repolarization)** 이라 한다.

수십억 개 심근세포에서 이 일이 특정 순서로 번져 나가면, 심장 전체가 하나의 움직이는
전기 쌍극자(dipole)처럼 행동한다. 그 전기장이 몸통이라는 전도체를 통해 피부 표면까지 전달된다.
피부에 전극을 붙이고 두 지점 사이의 **전위차를 시간에 대해 기록한 것**이 심전도다.

여기서 중요한 결론이 나온다.

> 심전도는 심장의 사진이 아니라, 심장 전기활동을 특정 방향으로 사영(projection)한 1차원 시계열이다.

단위는 밀리볼트(mV)다. 우리 데이터의 실측 진폭은 4절에 있다.

## 2. 한 박동의 파형 구조: P, QRS, T

정상 박동 하나는 세 덩어리로 나뉜다. 각각이 심장의 다른 부위, 다른 사건에 대응한다.

```
      R
      /\
     /  \          T
 P  /    \        /‾\
_/\_/      \_____/   \____
    Q   S
 |--|      |----|
 PR         QT
```

| 성분 | 생리적 사건 | 정상 범위 (교과서 값) |
|---|---|---|
| **P파** | 심방(atrium) 탈분극. 심방이 수축해 혈액을 심실로 밀어 넣음 | 폭 0.12초 미만, 높이 0.25mV 미만 |
| **PR간격** | 전기가 심방에서 방실결절(AV node)을 거쳐 심실까지 도달하는 시간 | 0.12 ~ 0.20초 |
| **QRS복합** | 심실(ventricle) 탈분극. 심장에서 가장 큰 근육 덩어리라 진폭이 가장 큼 | 폭 0.12초 미만 |
| **T파** | 심실 재분극 | QT간격 약 0.35 ~ 0.44초 (심박수 의존) |

**진단은 대부분 이 성분들의 모양, 폭, 높이, 간격이 정상에서 벗어났는지를 본다.**
5절의 다섯 개 클래스가 전부 이 관점에서 정의된다.

### 우리 데이터에서 직접 확인

`ecg_id 1`의 리드 II에서 R피크 간격(RR간격)을 재면 대부분 0.91 ~ 0.97초로 일정하다.
심박수로 환산하면 `60 / 0.93 = 약 64 bpm`이고, 정상 범위(60 ~ 100 bpm) 안이다.
이 레코드의 판독문이 `sinusrhythmus periphere niederspannung`
(동율동, 말초 저전압)인 것과 일치한다.

(주: 위 계산은 단순 임계값 피크 검출이라 한 박동을 두 번 센 구간이 하나 있었다.
정확한 R피크 검출은 Pan-Tompkins 같은 전용 알고리즘을 쓴다. 우리 모델은 R피크를
명시적으로 검출하지 않고 CNN이 알아서 학습한다.)

## 3. 12리드의 정체: 전극 10개, 리드 12개, 독립은 8개

여기가 ECG에서 엔지니어가 가장 헷갈리는 지점이고, 동시에 가장 할 말이 많은 지점이다.

### 전극과 리드는 다르다

- **전극(electrode)**: 피부에 붙이는 물리적 금속판. 12-lead ECG는 **10개**를 붙인다.
  사지 4개(양팔, 양다리. 다리 하나는 접지)와 가슴 6개(V1 ~ V6).
- **리드(lead)**: 두 지점 사이의 전위차 신호. 즉 **심장을 바라보는 하나의 각도**.
  10개 전극을 조합해 **12개** 리드를 만든다.

리드는 카메라 각도라고 생각하면 정확하다. 같은 심장을 12개 방향에서 본 것이다.
이래야 병변의 **위치**를 알 수 있다. 심근경색이 심장 아래쪽에 생겼는지 앞쪽에 생겼는지는
어느 리드에서 이상이 보이느냐로 판단한다.

| 그룹 | 리드 | 보는 평면 | 보는 부위 |
|---|---|---|---|
| 사지유도 (limb) | I, II, III, aVR, aVL, aVF | 전두면 (앞에서 본 평면) | 심장의 상하좌우 |
| 흉부유도 (precordial) | V1 ~ V6 | 수평면 (위에서 내려다본 단면) | 심장의 앞뒤 |

부위 이름은 진단명에 그대로 등장한다.
- **inferior (하벽)**: II, III, aVF
- **anterior (전벽)**: V1 ~ V4
- **lateral (측벽)**: I, aVL, V5, V6

5절에서 `IMI`(inferior myocardial infarction)가 나오면 II, III, aVF에서 이상이 보였다는 뜻이다.

### 12개 중 8개만 독립이다

사지유도 6개는 전극 3개(양팔, 왼다리)로 만든다. 3개 점으로 만들 수 있는 독립적인
전위차는 2개뿐이다. 나머지 4개는 선형 조합으로 유도된다. 아인트호벤 삼각형(Einthoven's triangle)
관계식이다.

```
III = II - I
aVR = -(I + II) / 2
aVL = (I - III) / 2
aVF = (II + III) / 2
```

**우리 데이터 500 레코드로 직접 검증했다.**

| 관계식 | 평균절대오차 | 신호 크기 대비 |
|---|---|---|
| `III == II - I` | 0.000249 mV | 0.284% |
| `aVR == -(I+II)/2` | 0.000333 mV | 0.397% |
| `aVL == (I-III)/2` | 0.000332 mV | 0.483% |
| `aVF == (II+III)/2` | 0.000328 mV | 0.384% |

오차 0.3% 수준이고 이건 저장 시 양자화 오차다. 관계식이 정확히 성립한다.

12x(500 x 1000) 행렬의 특이값을 보면 더 명확하다.

```
정규화 특이값: 1.000  0.912  0.504  0.360  0.340  0.286  0.266  0.228
               0.00086  0.00066  0.00063  0.00057
                  ^^^^ 9번째부터 3자리수 급락

유효 rank: 8 / 12
```

**결론: 12채널 입력의 실제 정보 차원은 8이다.**

모델링 관점에서 이게 뜻하는 것.

1. 입력 채널 4개가 수학적으로 잉여다. 첫 Conv1d 층은 중복 정보를 받고 있다.
2. 그럼에도 12채널을 그대로 넣는 이유는 (a) 임상 표준이고 배포 시 입력 규격을 바꾸면
   현장 호환성이 깨지며, (b) 선형 조합을 네트워크가 다시 배우는 비용이 사실상 0이고,
   (c) 공개 벤치마크가 12채널이라 비교 가능성이 유지되기 때문이다.
3. 다만 **압축이나 경량화가 필요하면 8채널 입력이 정보 손실 없는 첫 번째 카드**다.
   Orin 배포에서 입력 대역폭이 문제가 되면 여기부터 손댄다.

이 관찰은 CLIP의 이미지 패치와 대비하면 흥미롭다. 이미지 패치는 서로 독립적인 정보를
담지만, ECG의 12리드는 8차원 부분공간에 갇혀 있다. 인코더가 뽑아야 할 것은
채널 간 관계가 아니라 **시간축 패턴과 채널 간 상대적 크기 분포**다.

## 4. 진폭 스케일

PTB-XL 캐시 2000 레코드에서 계산한 리드별 진폭(mV)이다.

| lead | mean | std | p1 | p99 | max abs |
|---|---|---|---|---|---|
| I | -0.0006 | 0.159 | -0.295 | 0.710 | 3.47 |
| II | -0.0000 | 0.167 | -0.364 | 0.657 | 3.39 |
| III | 0.0005 | 0.159 | -0.552 | 0.431 | 3.51 |
| aVR | 0.0003 | 0.143 | -0.631 | 0.256 | 2.92 |
| aVL | -0.0005 | 0.135 | -0.297 | 0.569 | 3.34 |
| aVF | 0.0003 | 0.142 | -0.389 | 0.468 | 3.40 |
| V1 | 0.0002 | 0.244 | -0.946 | 0.526 | 8.32 |
| **V2** | -0.0006 | **0.349** | -1.359 | 0.844 | **11.10** |
| V3 | -0.0014 | 0.342 | -1.146 | 0.974 | 9.31 |
| V4 | -0.0012 | 0.298 | -0.775 | 1.168 | 11.14 |
| V5 | -0.0004 | 0.287 | -0.592 | 1.217 | 8.25 |
| V6 | -0.0005 | 0.273 | -0.552 | 1.086 | 6.49 |

읽어야 할 것 두 가지.

**흉부유도가 사지유도보다 2배 이상 크다.** V2 ~ V4는 전극이 심장 바로 위에 붙어 있어
전기장 감쇠가 적다. 사지유도는 팔다리까지 거리가 멀어 신호가 작아진다.
이래서 **채널별로 따로 정규화**한다. 전체 하나의 평균/표준편차로 정규화하면
사지유도가 뭉개진다.

**평균이 전부 0에 가깝다.** 기저선(baseline)이 0mV 근처에 맞춰져 있다는 뜻이다.
다만 최대 절댓값이 11mV까지 튄다. 이건 병적 신호일 수도 있고 전극 접촉 불량 같은
잡음일 수도 있다. PTB-XL은 `baseline_drift`, `static_noise`, `burst_noise`,
`electrodes_problems` 컬럼으로 잡음 유형을 메타데이터에 기록해 두었다.
1단계에서는 쓰지 않았지만, 성능이 안 나올 때 잡음 레코드를 걸러 보는 것이 개선 카드다.

## 5. superdiagnostic 5개 클래스가 실제로 무엇인가

우리 모델이 예측하는 5개다. PTB-XL은 SCP 코드 44개를 이 5개로 묶는다.

### NORM (정상)

하위 코드 1개(`NORM`). 데이터의 44.5%로 가장 많다.
"이상 소견 없음"이므로 다른 진단과 거의 배타적이다 (6절 참조).

### MI: 심근경색 (Myocardial Infarction)

관상동맥이 막혀 심근이 괴사한 상태, 또는 과거에 괴사했던 흔적.
괴사한 조직은 전기를 전달하지 못하므로 파형이 변한다.

파형 소견: 병적 Q파(넓고 깊은 Q), ST분절 상승 또는 하강, T파 역전.

**하위 SCP 코드 14개가 전부 위치 조합이다.**

| 코드 | 의미 |
|---|---|
| IMI | inferior 하벽 |
| ASMI | anteroseptal 전중격 |
| ILMI | inferolateral 하측벽 |
| AMI | anterior 전벽 |
| ALMI | anterolateral 전측벽 |
| LMI | lateral 측벽 |
| IPMI / IPLMI | inferoposterior 계열 |
| PMI | posterior 후벽 |
| INJAS / INJAL / INJIN / INJLA / INJIL | subendocardial injury (심내막하 손상), 부위별 |

이래서 12리드가 필요하다. 단일 채널이면 "경색이 있다"까지는 가능해도
"어느 벽인가"는 불가능하다.

### STTC: ST/T 변화 (ST/T Change)

ST분절과 T파의 이상. MI보다 **비특이적**이다. 원인이 다양하다.

| 코드 | 의미 |
|---|---|
| NST_ | 비특이적 ST 변화 |
| NDT | 비진단적 T파 이상 |
| ISC_, ISCAL, ISCIN, ISCIL, ISCAS, ISCLA, ISCAN | 허혈(ischemia), 부위별 |
| LNGQT | QT간격 연장. 치명적 부정맥 위험 인자 |
| DIG | 디기탈리스(강심제) 효과 |
| EL | 전해질 이상 또는 약물 |
| ANEUR | 심실류(ventricular aneurysm) 동반 ST-T 변화 |

허혈(ischemia)은 혈류 부족이지만 아직 괴사하지 않은 상태다. MI의 전 단계에 가깝다.
그래서 MI와 STTC는 함께 나타나는 경우가 많다 (6절).

### CD: 전도장애 (Conduction Disturbance)

전기 신호가 심장 내부 전달 경로를 따라 제대로 퍼지지 않는 상태.
배선 문제이지 근육 문제가 아니다.

| 코드 | 의미 |
|---|---|
| 1AVB / 2AVB / 3AVB | 방실차단 1도 / 2도 / 3도. PR간격 연장에서 완전 차단까지 |
| CRBBB / IRBBB | 우각차단 완전 / 불완전 |
| CLBBB / ILBBB | 좌각차단 완전 / 불완전 |
| LAFB / LPFB | 좌전분지 / 좌후분지 차단 |
| IVCD | 비특이적 심실내 전도지연 |
| WPW | Wolff-Parkinson-White 증후군. 부전도로가 존재 |

파형 소견: QRS 폭 증가(각차단), PR간격 연장(방실차단), delta파(WPW).
**시간축 폭이 핵심 단서**라서 샘플링 레이트가 성능에 영향을 줄 수 있는 클래스다 (7절).

### HYP: 비대 및 확대 (Hypertrophy)

심근이 두꺼워지거나 심방이 늘어난 상태. 고혈압, 판막질환의 결과인 경우가 많다.
근육량이 늘면 전기 신호가 커지므로 **QRS 진폭 증가**로 나타난다.

| 코드 | 의미 |
|---|---|
| LVH | 좌심실비대 |
| RVH | 우심실비대 |
| LAO/LAE | 좌심방 확대 |
| RAO/RAE | 우심방 확대 |
| SEHYP | 중격 비대 |

데이터의 12.4%로 가장 적고, 우리 모델에서 AUROC 0.8956으로 가장 낮다.
진단 기준 자체가 진폭 임계값(Sokolow-Lyon 지수 등) 기반이라 경계가 모호한 것도 원인이다.

### 여기 없는 것: 부정맥

**superdiagnostic 5개에 부정맥(arrhythmia)은 없다.** 부정맥은 리듬의 문제이고
PTB-XL에서는 `rhythm` 층위(12개 클래스, AFIB 심방세동, SR 정상동율동 등)에 들어간다.

CLAUDE.md에는 1단계 목표가 "부정맥 분류"라고 적혀 있지만, 실제 구현은
superdiagnostic 진단 분류다. 표준 벤치마크와 비교 가능하고 2단계 판독문 생성에
직결되기 때문에 이렇게 정했다. **면접에서 이 차이를 먼저 짚고 이유를 말할 수 있어야 한다.**

## 6. 클래스 동시출현이 말해주는 것

전체 21388 레코드의 동시출현 행렬이다. 대각선은 해당 클래스 총 개수다.

| | NORM | MI | STTC | CD | HYP |
|---|---|---|---|---|---|
| **NORM** | 9514 | 1 | 33 | 415 | 5 |
| **MI** | 1 | 5469 | 1339 | 1794 | 818 |
| **STTC** | 33 | 1339 | 5235 | 1066 | 1509 |
| **CD** | 415 | 1794 | 1066 | 4898 | 787 |
| **HYP** | 5 | 818 | 1509 | 787 | 2649 |

**NORM은 사실상 배타적이다.** MI와 동시에 붙은 게 21388건 중 1건뿐이다.
NORM AUROC가 0.9347로 가장 높은 이유가 여기 있다. 문제가 쉽다.

**단 NORM과 CD가 415건 겹친다.** 불완전 우각차단(IRBBB)이나 1도 방실차단처럼
임상적으로 무해하다고 보는 전도 이상이 있으면 판독의가 "그 외 정상"으로 적는 경우다.
멀티라벨 설정이 아니었으면 이 415건을 표현할 방법이 없다.

**MI, STTC, CD는 서로 강하게 동반한다.** MI의 33%가 CD를 동반하고 24%가 STTC를 동반한다.
관상동맥 질환이 심근 괴사와 전도로 손상을 동시에 일으키기 때문이다.
생리적으로 당연한 결과지만, 모델 입장에서는 **클래스 경계가 겹친다**는 뜻이고
이게 MI/STTC/CD의 AUROC가 0.90 근처에 머무는 이유 중 하나다.

**HYP는 STTC와 가장 강하게 붙는다** (1509 / 2649 = 57%).
좌심실비대가 있으면 이차적으로 ST-T 변화가 따라오는 것이 전형적이다.

이 표는 멀티라벨 + BCE 설계의 정당화다. softmax 단일 라벨이었으면
전체의 24%를 표현할 수 없다.

## 7. 100Hz와 500Hz 중 무엇을 쓸 것인가

PTB-XL은 같은 녹음을 두 해상도로 제공한다. 원본이 500Hz이고 100Hz는 다운샘플이다.

```
records500/  (12, 5000)  원본
records100/  (12, 1000)  다운샘플    <- 1단계에서 사용
```

**나이퀴스트 관점.** 100Hz 샘플링은 50Hz까지 표현한다.
QRS복합의 주요 주파수 성분은 대략 10 ~ 40Hz 대역이므로 100Hz로도 QRS 모양은 보존된다.
다만 **고주파 성분이 중요한 소견은 손실된다.** 병적 Q파의 미세한 노치,
delta파의 시작점, 페이스메이커 스파이크(1ms 수준) 같은 것이 그렇다.

**실무적 근거.**
1. 공개 벤치마크가 100Hz 기준이라 비교 가능성이 유지된다
2. 전체 데이터가 1.03GB로 줄어 RAM에 상주한다. 학습 epoch가 4.8초다
3. Orin 배포 시 입력 텐서가 5분의 1이라 지연에 유리하다

**바꿔야 할 신호.** CD 클래스(QRS 폭, delta파)에서 성능이 정체되면 500Hz를 시도한다.
config에서 `sampling_rate: 500` 한 줄이고 데이터는 이미 받아 두었다.
다만 입력 길이가 1000에서 5000으로 늘어나 stem의 stride 설계를 다시 봐야 하고,
그러면 2단계 ECG 토큰 수(현재 32)도 바뀐다.

## 8. SCP-ECG 표준과 라벨 층위

**SCP-ECG**(Standard Communication Protocol for computer assisted electrocardiography)는
심전도 판독 소견을 코드로 표준화한 유럽 표준이다 (EN 1064 / ISO 11073-91064).
`NORM`, `IMI`, `CLBBB` 같은 코드가 여기서 온다.

PTB-XL은 각 레코드에 `{코드: 확신도}` 형태로 라벨을 붙였다.

```python
{'NORM': 100.0, 'LVOLT': 0.0, 'SR': 0.0}
```

확신도 0.0은 "확신도 정보 없음"이지 "아니다"가 아니다.
**그래서 우리 파이프라인은 확신도로 필터링하지 않는다** (공개 벤치마크 관행과 동일).

`scp_statements.csv`가 각 코드를 상위 범주로 매핑한다. 층위가 여러 개다.

| 층위 | 클래스 수 | 성격 |
|---|---|---|
| superdiagnostic | 5 | 진단 대분류. **우리가 쓰는 것** |
| subdiagnostic | 23 | 진단 중분류 |
| diagnostic | 44 | 진단 전체 |
| form | 19 | 파형 형태 소견 |
| rhythm | 12 | 리듬. 부정맥이 여기 |
| all | 71 | 전부 |

`diagnostic == 1`인 문장 44개만 superdiagnostic으로 매핑된다.
21799개 중 411개는 rhythm이나 form 소견만 있어서 superdiagnostic이 비고, 그래서 제외했다.

## 9. 읽어야 할 논문

### 데이터와 벤치마크 (필수)

**Wagner et al., "PTB-XL, a large publicly available electrocardiography dataset",
Scientific Data 7:154, 2020.**
데이터셋 원 논문. 수집 방법, 라벨링 절차, `strat_fold`를 어떻게 만들었는지가 나온다.
"왜 fold 1-8/9/10 분할을 그대로 썼는가"에 답하려면 이걸 읽어야 한다.
핵심: 환자 단위 층화이고 fold 9, 10은 사람이 검증한 라벨 비율이 높다.

**Strodthoff et al., "Deep Learning for ECG Analysis: Benchmarks and Insights from PTB-XL",
IEEE Journal of Biomedical and Health Informatics, 2021.**
우리가 비교 대상으로 삼는 벤치마크. 여러 아키텍처(inception1d, xresnet1d, LSTM 등)를
같은 프로토콜로 비교했고 superdiagnostic macro AUC 0.92 ~ 0.93 대역을 보고한다.
평가 프로토콜(macro AUROC, 부트스트랩 신뢰구간)의 출처다.

### 멀티모달 (2단계 필수)

**Radford et al., "Learning Transferable Visual Models From Natural Language Supervision"
(CLIP), ICML 2021.**
이미지 인코더와 텍스트 인코더를 대조학습으로 같은 공간에 정렬한다.
우리 프로젝트는 CLIP식 대조학습을 쓰지는 않지만, "인코더 출력이 언어와 정렬 가능한
표현이어야 한다"는 전제를 공유한다.

**Liu et al., "Visual Instruction Tuning" (LLaVA), NeurIPS 2023.**
이 프로젝트의 직접적 레시피. 핵심은 두 가지다.
(a) 고정된 비전 인코더 + 학습 가능한 선형 프로젝터로 시각 토큰을 LLM 임베딩 공간에 투사
(b) 2단계 학습. 먼저 프로젝터만 정렬 학습, 다음에 instruction tuning
우리는 CLIP ViT 자리에 ResNet1d를, 이미지 패치 토큰 자리에 32개 ECG 토큰을 넣는다.

**Hu et al., "LoRA: Low-Rank Adaptation of Large Language Models", ICLR 2022.**
LLM 가중치를 통째로 갱신하지 않고 저랭크 행렬 두 개만 학습한다.
RTX 2060 6GB에서 LLM을 파인튜닝할 수 있는 이유다.

### 선택

**Ribeiro et al., "Automatic diagnosis of the 12-lead ECG using a deep neural network",
Nature Communications 11:1760, 2020.**
대규모 임상 데이터로 학습한 12리드 ECG 딥러닝의 대표 사례.
전문의 수준과 비교한 평가 방식이 참고가 된다.

**Oh et al., "ECG-QA: A Comprehensive Question Answering Dataset Combined With
Electrocardiogram", NeurIPS 2023 Datasets and Benchmarks.**
CLAUDE.md에서 2단계 데이터 보강 후보로 언급한 것. PTB-XL 위에 질의응답 쌍을 얹었다.

## 10. 면접에서 나올 질문과 답변 포인트

**"12리드 ECG를 왜 12채널로 넣었나요?"**
임상 표준이고 벤치마크 비교 가능성 때문. 다만 실제 정보 차원은 8이다.
사지유도 6개 중 4개가 나머지 2개의 선형 조합이고, 직접 검증했다.
12x(500x1000) 행렬의 SVD에서 9번째 특이값부터 3자리수 떨어진다.
경량화가 필요하면 8채널 입력이 정보 손실 없는 첫 카드다.

**"왜 멀티라벨인가요? 진단은 하나 아닌가요?"**
전체의 24%가 라벨 2개 이상이다. MI의 33%가 CD를 동반한다.
관상동맥 질환이 괴사와 전도로 손상을 동시에 일으키기 때문이고, 이건 생리적으로 당연하다.
softmax 단일 라벨이면 이 24%를 표현할 수 없다. 그래서 sigmoid 5개 + BCE다.

**"왜 AUROC를 주 지표로 썼나요?"**
클래스 불균형(HYP 12.4% ~ NORM 44.5%)에서 정확도는 무의미하고, 임계값에 의존하지 않는
순위 기반 지표라서. 클래스별로 따로 구해 macro 평균하면 소수 클래스가 다수 클래스에
묻히지 않는다. 벤치마크와 프로토콜을 맞추는 목적도 있다.

**"분할을 어떻게 했나요?"**
PTB-XL이 제공하는 `strat_fold`를 그대로 썼다. 직접 나누면 안 된다.
21799 레코드가 18869 환자에서 나왔으므로 한 환자가 여러 레코드를 갖는다.
무작위 분할하면 같은 환자가 학습과 테스트에 걸쳐 성능이 부풀려진다.

**"정규화를 왜 채널별로 했나요?"**
흉부유도(V2 std 0.349)가 사지유도(aVL std 0.135)보다 2.5배 크다.
전극이 심장에 더 가까워 감쇠가 적기 때문이다.
전체 하나의 통계로 정규화하면 사지유도가 뭉개진다.
그리고 통계는 학습 fold에서만 산출했다. 전체로 내면 테스트 정보가 샌다.

**"100Hz면 정보 손실 아닌가요?"**
QRS 주요 성분이 10 ~ 40Hz라 나이퀴스트상 QRS 형태는 보존된다.
다만 페이스메이커 스파이크나 delta파 시작점 같은 고주파 소견은 손실된다.
CD 클래스에서 성능이 정체되면 500Hz로 올릴 계획이고 데이터는 이미 확보했다.

**"부정맥 분류라고 하셨는데 클래스에 부정맥이 없네요?"**
정확한 지적이다. 부정맥은 PTB-XL의 rhythm 층위(12클래스)이고
우리가 쓴 건 superdiagnostic 진단 분류다. 표준 벤치마크와 비교 가능하고
2단계 판독문 생성으로 이어지는 진단 카테고리라서 이쪽을 택했다.

**"성능이 벤치마크보다 낮은데요?"**
0.9143 대 0.92 ~ 0.93. 두 가지를 짚는다.
(a) 데이터셋 버전이 다르다. 인용되는 수치는 v1.0.1(21430) 기준이고 우리는 v1.0.3(21388)이다.
(b) 과적합이 남아 있다. train loss는 계속 내려가는데 val loss가 epoch 9부터 반등한다.
증강을 넣지 않은 순수 베이스라인이고, 정규화 강화가 다음 단계다.

**"2단계에서 ECG를 어떻게 언어로 바꾸나요?"**
인코더의 `forward_features`가 (B, 512, 32)를 낸다. 시간축 32스텝이 32개의 ECG 토큰이다.
프로젝터가 512를 LLM 임베딩 차원으로 올려서 프롬프트 앞에 끼워 넣는다.
LLaVA에서 CLIP 패치 토큰이 놓이는 자리와 같다. 인코더는 동결하고 프로젝터와 LoRA만 학습한다.

**"학습 데이터의 판독문은 어떤 상태인가요?"**
`report` 컬럼이 원문인데 59%가 독일어, 30%가 영어로 섞여 있다.
고유 문장은 9887개뿐이고 6813건은 기계 자동생성 초안이다.
Qwen2.5-0.5B는 다국어 능력이 약해서 그대로 쓰면 출력 언어가 섞인다.
영어 서브셋으로 통제하는 것이 현재 계획이다.
